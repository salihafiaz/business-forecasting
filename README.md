# Business Forecasting & Time Series Analysis

## Overview

This repository showcases forecasting projects completed
as part of MGTSC 405 – Forecasting at the Alberta School
of Business, University of Alberta.

These projects demonstrate the application of quantitative
forecasting techniques to real-world datasets, with an
emphasis on model selection, forecast accuracy, and
data-driven business decision-making.

## Featured Projects

### 1. Forecasting Passenger Air Transport Prices

Analyzed historical passenger air transport price data
across 19 Euro Area countries using data from the
Federal Reserve Economic Data (FRED) database.

- Identified trends, seasonality, and structural changes.
- Adjusted for a structural break in April 2022.
- Evaluated five forecasting model specifications.
- Compared model performance using forecast error metrics.
- Recommended Seasonal Naïve Model 2 for short-term
  forecasting.

### 2. Edmonton International Airport Passenger Forecasting

Analyzed historical international passenger volumes
to identify an appropriate forecasting model for
Edmonton International Airport.

- Evaluated trends, seasonality, and stationarity.
- Compared exponential smoothing and ARIMA models.
- Applied detrending techniques to improve model performance.
- Evaluated forecast accuracy using MAPE, MSE, and RMSE.
- Recommended a detrended seasonal ARIMA model.
